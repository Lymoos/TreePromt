# Этап 7.9. Окно проекта, скиллы задачи и настоящие проекты

Решение владельца, 19.10.2026: AiCrew должен работать над настоящими проектами, в том числе над PromptTree и самим AiCrew.

- **Окно проекта.** У проекта своё окно: описание для ИИ, файлы, код (репозиторий или локальная папка). Всё это нужно, чтобы агенты знали, с чем работают.
- **Скиллы задачи.** В самой задаче можно выбрать нужный скилл.
- **Макет:** `design/project-v1.html`.

## 1. Что хранится и где

| Что | Где | Кто видит |
|---|---|---|
| Описание для ИИ | сервер, у проекта (синхронизируется, как имя проекта) | все устройства; агенты — в каждой задаче проекта |
| Файлы проекта | сервер, `/opt/prompttree/files/<проект>/` (том Docker с бэкапом), до 20 МБ на файл и до 200 МБ на проект | приложения скачивают по запросу; служба кладёт копию агенту только для чтения |
| Код | привязка к ПК со службой: папка или git-адрес + ветка + шаблон проверки | служба этого ПК; на сервере только описание привязки |
| Скиллы проекта | обязательные и запрещённые; это та же политика скиллов репозитория из 7.5, теперь из окна | Manager и сервер при проверке плана |
| Скиллы задачи | поле AI Task (синхронизируется) | уходят с задачей в AiCrew как `required_skills` |

## 2. Как агенты получают контекст

- **Перед текстом задачи** служба добавляет блок «О проекте»: описание для ИИ и список файлов. Файлы смонтированы в контейнер только для чтения (`/project`).
  - Так у Claude, Codex и Junior.
  - У Manager'а тоже: план строится с учётом контекста.
- **Описание и файлы — данные, а не команды.** Они идут в блоке `<untrusted>`, как сейчас запрос Manager'у. Секреты из описания вырезает сканер 7.6.

## 3. Привязка кода из окна

- **Папка на ПК.** В окне указывается путь. Служба ПК получает заявку и проверяет её:
  - папка существует;
  - это git-репозиторий;
  - папка не внутри профиля владельца.

  После этого служба привязывает её так же, как сейчас `aicrew-host add-repo`. Ответ виден в окне: «Привязан к DESKTOP-…» или причина отказа.
- **Git-репозиторий.** Служба клонирует его в `D:\aicrew-work\<имя>`.
  - Для приватных репозиториев нужен доступ: вход в GitHub делает владелец на ПК (`gh auth login` или ключ SSH). Сам я токены не ввожу.
- **Шаблон проверки:** Flutter, Go, Web, Roblox или свои команды.
- **В основную ветку**, как и раньше, переносит только владелец (`promote`).

## 4. PromptTree и AiCrew как проект AiCrew

Привязываем `C:\MyProfile\My_project\TreePromt` к проекту «PromptTree и AiCrew».

- **Проверка (свои команды):**
  - `gofmt`, `go vet`, `go test` для `backend` (с тестовой базой) и `aicrew`;
  - `flutter analyze` и `flutter test --exclude-tags golden` для `shared` и трёх приложений.
  - Это тяжело: перед слиянием проверяется всё, в попытке — только затронутые пакеты.
- **Контракт архитектуры `architecture.yaml`.** Пути, которые всегда требуют вашего одобрения, даже в полуавтомате:
  - `.github/`, `backend/deploy/`, `backend/migrations/`;
  - `aicrew/internal/secrets`, `aicrew/internal/runas`, `aicrew/internal/secretscan`;
  - `aicrew/images/`, `aicrew/skills/`;
  - `design/`.
- **Работающая служба сама себя не меняет.** Изменения AiCrew приходят в `aicrew/integration`, а в `main` их переносите вы. Новую службу собираем, как сейчас, из `main`.
- **Изменения интерфейса** — с макетом и вашим согласованием. Их отмечает `touches_ui`, и Tech Lead проверяет правило из скилла `prompttree-design-system`.

## 5. Порядок работ

1. **Сервер.**
   - Поле «описание для ИИ» у проекта.
   - Хранилище файлов: загрузка, список, скачивание, удаление, лимиты.
   - Заявки на привязку кода.
   - Поле скиллов у AI Task.
2. **Служба.**
   - Блок «О проекте» и файлы в контейнере.
   - Выполнение заявок на привязку: папка или клон.
   - Свои команды проверки.
3. **Приложения.** Окно проекта с тремя вкладками и выбор скиллов в AI Task (ПК и телефон, по макету).
4. **Самопроект.** `architecture.yaml` и профиль проверки для TreePromt, привязка, первая пробная задача.

## Проверка

- **Тесты:** сервер (лимиты файлов, права, заявки), служба (контекст в промпте, монтирование, заявки), приложения (окно, чипы скиллов, снимки экрана в обеих темах).
- **Вживую:**
  - задача в полигоне видит описание и файл;
  - привязка папки из окна;
  - одна небольшая задача в самом PromptTree проходит до «ждёт решения».
