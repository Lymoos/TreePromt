Что согласовать

  1. Вход: правый клик по проекту → «Окно проекта…» (на телефоне — долгое нажатие); окно занимает место редактора, три вкладки.
  2. «Описание для ИИ» и файлы проекта уходят агентам в каждую задачу проекта; файлы — только для чтения, до 20 МБ на файл.
  3. Код: папка на ПК с AiCrew или git-репозиторий (служба скачивает сама в D:\aicrew-work). Привязка — к конкретному ПК; в main по-прежнему переносите только вы.
  4. Скиллы проекта: обязательные (в рамке) и запрещённые (зачёркнуты). Скиллы задачи — строка чипов под заголовком AI Task и список с поиском.
