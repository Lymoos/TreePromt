## Канбан AiCrew — согласовано 12.10.2026 по макету `kanban-v1.html`

| Тема | Решение |
|---|---|
| Раскладка | **ПК — A · Доска**: шесть колонок (очередь, в работе, проверка, ждёт решения, слито, ошибки). **Телефон — B · Список**: группы по статусам, сверху «ждёт решения» и ошибки. Граница — ширина окна 900 px. |
| Состояние | Формой маркера, без цвета: круг — очередь, полукруг — в работе, контурный ромб — проверка, залитый ромб — ждёт решения, квадрат — слито, перечёркнутый квадрат — ошибка. |
| Пауза (инцидент) | Инвертированная полоса над доской с «Возобновить»; кнопка «Остановить всё» на это время скрыта. |
| Решения | На карточке: «Слить», «Вернуть с комментарием…» (поле прямо в карточке); у плана — галочки задач, «Утвердить план / выбранные», «Отклонить…». |
| Вход | Пункт «AiCrew» в боковой панели ПК над «Корзиной» и в меню «…» на телефоне; только при подключённом сервере. |
