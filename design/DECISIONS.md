# Дизайн-решения PromptTree

Согласовано с Максимом 08.10.2026 по концепту `concept-v1.html`.

| Тема | Решение |
|---|---|
| Иконка | **C · Плитка-узел**: залитая плитка (rx 5), внутри квадрат-проект и две ветви-файла; внутренние элементы цвета фона. SVG — в `concept-v1.html`, объект `ICONS.C`. |
| Левая панель | **C · Активная ветвь**: иконок-папок нет, иерархия по отступу (16 px на уровень); линии рисуются только на пути от проекта до открытого файла. |
| Маркеры | Проект — залитый квадрат. Папка — без маркера (вес 500, счётчик, шеврон). Raw Note — кружок, название приглушено. AI Task — ромб: пустой = не структурирована, залитый = структурирована, наполовину = есть правки после структурирования. |
| Шрифт | Onest (UI) + JetBrains Mono (служебные подписи). **Предварительно**: пересмотреть в реальном приложении. |
| Палитра | Только ч/б и серые, светлая и тёмная темы (токены — в `concept-v1.html`, `:root`). |
