# PromptTree — мобильное приложение

Flutter, Android и iOS. Почти вся логика и общие виджеты — в [`../shared`](../shared): локальная БД (Drift/SQLite), синхронизация, API, тема, панель-дерево (вариант C), маркеры, иконка C.

## Экраны

| Экран | Что делает |
|---|---|
| Вход | адрес сервера, email, пароль; «Первый запуск: создать владельца»; «Работать без сервера» |
| Дерево | проекты → папки → файлы, линии только до открытого файла; «+» создаёт в выбранной папке; долгое нажатие — переименовать, переместить, сменить тип, удалить |
| Редактор | автосохранение через 300 мс и при сворачивании; «Скопировать задачу» → «Удалить задачу?»; «Структурировать» появится на этапе 6 |
| Две версии текста | разбор конфликта: оставить одну или собрать итог |
| История версий | просмотр и откат |
| Корзина | всё удалённое можно вернуть |

## Запуск

```bash
flutter run
```

Для локального сервера на компьютере из эмулятора Android адрес — `http://10.0.2.2:8080` (http разрешён только в debug-сборке).

## Тесты

```bash
flutter test
```

Скриншоты экранов (светлая и тёмная тема) лежат в `test/goldens/`. Обновить их:

```bash
flutter test --update-goldens test/screenshots_test.dart
```

Иконки лаунчера генерируются из того же рисунка, что и `AppIcon`:

```bash
flutter test test/tool/launcher_icons_test.dart
```
